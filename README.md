# UmraMandiri
Situs statis (HTML/CSS/JS). Tanpa build.
- Deploy: push ke GitHub, impor di Vercel (Framework: Other), selesai.
- Tarif kalkulator: edit objek `R` di `kalkulator.html` (angka saat ini hanya contoh).
- Nomor WhatsApp: ubah `WA` di `assets/app.js` dan tautan `wa.me` di HTML.
- Testimoni: isi blok "Cerita Jamaah" di `index.html`. Foto pendiri: ganti blok `.av` dengan `<img>`.
